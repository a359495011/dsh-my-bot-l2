我的 BOT · 学员版

女装短视频带货方法论教练：选品判断、口播脚本、达人筛选与报价、客服异议、复盘指标。装完在侧栏选「我的 BOT·学员版」就能用。

第 1 步

装 DeepSeek Harness 桌面版

到 deepseek.com/harness/ 下载 Windows 版，一路下一步装完，打开。

第 2 步

添加插件源

打开「设置 → 插件」，找到「插件源 / 市场索引 / Index URL」一栏，把下面的地址粘进去保存：

https://raw.githubusercontent.com/a359495011/dsh-my-bot-l2/main/index.json

不同版本菜单位置略有差异，认准「插件源」「市场索引」「Index」这几个字即可。

第 3 步

安装「我的 BOT·学员版」

回到「插件 → 发现」，刷新后能看到「我的 BOT·学员版」，点安装，等它装完。

如果发现页没有刷新出条目，关掉设置面板再打开一次；还不行就把第 2 步的地址复制到「添加插件 → 安装第三方插件」里试试。
第 4 步

放好方法论（五篇）

学员版的五篇方法论放在技能目录里，放进去才生效。两种方式任选：

方式 A（推荐）：下载仓库里的 install.ps1，右键「使用 PowerShell 运行」，它会自动找安装位置并复制到 %USERPROFILE%\.dsh\skills\，跑完会打印是否成功。

方式 B（手动）：在仓库页面打开 skills/mybot-l2-workstyle 文件夹，下载整个文件夹，放到 C:\Users\你的用户名\.dsh\skills\ 下面，最终路径要是 ...\.dsh\skills\mybot-l2-workstyle\SKILL.md。

第 5 步

配一个模型

打开「设置 → 模型 → 添加模型供应商」，用你自己的模型账号。以 DeepSeek 开放平台为例：

项目填什么
协议OpenAI Chat Completions
Base URLhttps://api.deepseek.com
API Key你自己的 Key（在 platform.deepseek.com 创建）
模型deepseek-chat

其他家的模型也一样，只要它兼容 OpenAI 协议，把 Base URL、Key、模型名换成那家的即可。

第 6 步

开始用

新建一个会话，在人格列表里选「我的 BOT·学员版」，第一句可以这样说：

我有一款女装新品要拍短视频，帮我把选品判断和口播脚本先过一遍。

它会先问你缺哪些资料，再按五篇方法论给结论和可执行清单。

说明

它能做什么、不能做什么

  • 能：按方法论判断一个款值不值得做、写 15～40 秒口播脚本、给达人筛选标准和报价思路、给客服异议应答、做复盘表。
  • 不能：替你看真实后台数据、替你跟达人谈价签合同、承诺销量或 GMV。抓不到的信息它会明确标「待确认」，不硬编。
  • 红线：不用「最」「第一」「国家级」等绝对化用语，不做医疗功效宣称，不引导站外私下交易。
学员版不含底价、客户名单、寄样记录这些内部数据，拿到的只是方法论。
