# 女装选品判断方法（脱敏通用版）

> 用途：给一款女装/女裤做「推不推」的判断，输出可复核的结论，不靠感觉。
> 规则：所有判断基于你手上真实拿到的资料；没有的字段写「缺」，不补常识。

## 一、先回答四个问题

1. 卖给谁：年龄段、身材特征、消费场景（通勤/休闲/约会/居家）。
2. 什么价格带：你过去 30 天成交客单价是多少？新款价格要在它的 ±20% 内，否则人群错配。
3. 毛利够不够：零售价 − 供应价 − 运费 − 退货损耗，剩下的才是你能投的钱。
4. 供应稳不稳：库存能不能撑 2 周动销，断货能不能补，退换货谁承担。

四个问题答不上来，先别判断款，先补资料。

## 二、前置清单（缺一项就不评估）

| 字段 | 为什么必须有 |
|---|---|
| 款号 | 后面所有记录都用它对齐 |
| 裤型/版型（直筒/阔腿/锥形/微喇） | 决定适合人群和卖点表述 |
| 面料成分 | 决定价格合理性和洗护话术 |
| 尺码表（腰围/臀围/裤长/大腿围） | 客服和短视频都要用；没有就标缺 |
| 零售价 | 判断价格带 |
| 供应价/起订量 | 算毛利 |
| 库存 > 0 | 卖断货会伤账号 |
| 拍摄素材（至少 5 张实拍 + 1 段视频） | 没有素材出不了内容 |
| 信息状态 | 标「待补充」的款不进入评估 |

## 三、六维打分（100 分）

| 维度 | 分值 | 评分参考 |
|---|---:|---|
| 人群匹配 | 25 | 受众年龄/身材/场景高度重合 25；部分重合 15；不重合 0；无数据按缺项 |
| 价格带 | 20 | 在你成交客单 ±10% 内 20；±20% 内 12；超出 0；无数据按缺项 |
| 版型普适性 | 15 | 直筒/宽松对多数身材友好 15；挑身材 8；极挑 0 |
| 面料与季节 | 15 | 当季可穿、面料常见好打理 15；反季或难打理 5 |
| 供应稳定性 | 15 | 库存足、可补货、退换政策清楚 15；部分缺 8；不可补 0 |
| 视觉表现力 | 10 | 实拍质感好、有对比场景 10；素材一般 5 |

等级：
- ≥ 80：主推，排内容
- 60–79：备选，补数据再定
- 40–59：观察，不投流量
- < 40：不推

## 四、快速否决项（命中一条直接不推）

1. 库存 < 50 且 2 周内不可补。
2. 无尺码表或无成分表。
3. 零售价与你的粉丝消费力差 2 倍以上。
4. 起订量/押金超出你的现金流。
5. 供应商说不清退换责任。

## 五、结论怎么写

固定四行，缺一行就是没做完：

```
款号：XXX ｜ 版型：XXX ｜ 零售价：XXX ｜ 库存：XXX
结论：主推 / 备选 / 不推
理由：1. … 2. … 3. …（每条对应上面的维度）
数据缺口：缺什么、找谁补、什么时候要
```

## 六、常见误判

- 用零售价反推毛利，漏了运费和退货损耗。退货率按你历史数据算，没有就写缺。
- 只看款好看，不看粉丝买不买得起。
- 把「工厂说能补货」当承诺，不留补货周期。
- 一个款爆了立刻加量，没看供应能不能跟上。

## 七、交给上一步和下一步

- 上游要：供应商报价单、实拍素材、尺码表、成分表。
- 下游给：短视频选题（卖点）、客服话术（尺码/面料问答）、达人匹配（价格带字段）。
