# 我的 BOT·学员版（v0.1.0）

一个 DSH 预设包：女装短视频带货方法论教练。装上之后，DSH 人格列表里多一行「我的 BOT·学员版」。

它带五篇脱敏方法论：

| 文件 | 内容 |
|---|---|
| `references/01-选品判断.md` | 六维打分、否决项、结论写法 |
| `references/02-口播脚本结构.md` | 15–40 秒骨架、钩子、分镜、合规自检 |
| `references/03-达人筛选与报价.md` | 100 分制、报价公式、寄样、13 阶段状态机 |
| `references/04-客服异议处理.md` | 依据标签、四平台差异、十类异议、禁用语 |
| `references/05-复盘指标.md` | GMV/ROI/退款率口径、三层复盘、周节奏 |

## 安装（学员看这段）

1. 先装 DSH 桌面版：<https://deepseek.com/harness/>
2. 装本包：
   - 方式 A（推荐）：插件 → 添加插件 → 安装第三方插件，填本包地址（tgz 链接或本地绝对路径）。
   - 方式 B（命令行）：`dsh plugin --profile desktop add "<tgz 绝对路径或链接>"`
3. **复制方法论**：把本包 `skills/mybot-l2-workstyle` 整个目录复制到 `%USERPROFILE%\.dsh\skills\`（macOS/Linux：`~/.dsh/skills/`）。
4. 重启 GUI，新建会话，人格选「我的 BOT·学员版」。

第 3 步不能省：DSH 默认从 `~/.dsh/skills` 读技能，包里的技能目录不会被自动扫描。

## 配置模型

本包不自带模型。在「设置 → 模型」里配一个你自己的模型服务（OpenAI 兼容协议即可）。

## 第一次试

问它：`我有一款女裤，帮我判断推不推。` 它应该先问你要款号、价格、库存、素材，而不是直接下结论。

## 边界

- 不含任何一家的成本、底价、达人联系方式、客户数据。
- 不承诺销量，不保 GMV。
- 只是人格 + 方法论，不改宿主默认行为；卸载后人格行消失。
